# SDLC and QA Mapping

## SDLC Model
This project follows an Agile/iterative approach because development, testing, bug fixing, and regression testing are performed continuously.

## QA Activities

1. Requirement Phase
* Understand the requirements.
* Identify unclear or missing requirements.
* Identify possible test scenarios.


2. Design Phase
* Review the UI and application flow.
* Identify validations.
* Identify required test data.


3. Development Phase
* Prepare test cases.
* Prepare automation tests.
* Identify areas that need testing.


4. Testing Phase
* Execute functional testing.
* Execute smoke testing.
* Execute sanity testing.
* Execute regression testing.


5. Deployment Phase
* Perform smoke testing after deployment.
* Verify that critical features are working.

6. Maintenance Phase
* Re-test fixed defects.
* Perform regression testing after changes.
* Update test cases when required.

## QA Approach

QA is involved throughout the SDLC, not only after development is completed. Testing starts from the requirement phase and continues through development, testing, deployment, and maintenance.
