# Application Analysis

## Application Information

- **Application:** Tinubu Surety
- **URL:** https://alphanewui.tinubusurety.com

## Objective

To explore the Tinubu Surety application and identify its modules, test types, and user roles.

## Modules Identified

1. **Dashboard**
   - Table, filters, pagination, and search
   - Recently viewed bonds
   - Recently viewed accounts
   - My Tasks
2. **Bonds**
   - New Bond
   - View Bonds
   - Queues
   - Global Bond Block Number
   - Agency bond blocks
3. **Accounts**
   - New account
   - View accounts
   - Account queues
4. **Reports**
   - Status Inquiries
   - View reports
5. **Setup**
   - Bonds and Applications
   - Entities
   - Rating
   - Templates
6. **Agency Bond Blocks**
7. **Systems**
   - Access control
   - Configure
   - Submit Job
   - Logs
8. **Admin profile**
   - Log out
   - Change password
9. **Change Language**
10. **Quick Search**
